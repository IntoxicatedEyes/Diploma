# Паспорт датасета: Enriched English Word Features Dataset (27 колонок)

**Файл:** `data/datasets/enriched_27cols.csv`  
**Количество строк:** 4 822  
**Количество колонок:** 27

---

## 1. Общая информация

| Поле | Значение |
|------|---------|
| **Название** | English Word Linguistic Features Dataset (обогащённая версия на основе Mendeley и других открытых ресурсов) |
| **Автор / публикатор** | Не указан. Составлен из открытых лингвистических ресурсов (WordNet, BNC/COCA, NLTK, TextBlob) и данных Nisar Kangoo (Mendeley Data). |
| **Источник исходных меток сложности** | Kangoo, N. (2025). Dataset for classifying English words into difficulty levels by undergraduate and postgraduate students, Version 6. Mendeley Data. DOI: 10.17632/p2wrs7hm4z.6 |
| **Дополнительные источники признаков** | WordNet (семантика), BNC/COCA (частоты), NLTK (стоп-слова, части речи), TextBlob/VADER (полярность, субъективность), алгоритмы вычисления энтропии и фонетической сложности |
| **Лицензия составного датасета** | Не указана. Для учебного проекта — допустимо с атрибуцией всех компонентов. Для коммерческого — требуется проверка лицензий WordNet (CC BY-SA), BNC (требует лицензирования) и др. |

## 2. Структура данных

### Описание колонок

| Группа | Колонка | Тип | Описание | Источник |
|--------|---------|-----|----------|----------|
| **Исходные** | `word` | string | Английское слово | Mendeley |
| | `fre` | int | Частота слова в корпусе | Mendeley (или уточнённая) |
| | `len` | int | Длина слова в символах | Mendeley |
| | `Level` | int (0/1) | Уровень сложности | Mendeley (на основе difficult_ug/difficult_pg) |
| | `part_of_speech` | int (код) | Часть речи (числовой код) | NLTK/spaCy |
| **Семантические** | `Word_Sense_Count` | int | Количество смыслов (омонимия) | WordNet |
| | `synonym_count` | int | Количество синонимов | WordNet |
| | `hypernym_count` | int | Количество гиперонимов (родовых понятий) | WordNet |
| | `hyponym_count` | int | Количество гипонимов (видовых понятий) | WordNet |
| | `semantic_category` | int (код) | Семантическая категория | WordNet |
| **Частотные** | `IDF` | float | Inverse Document Frequency | Вычислено на основе корпуса |
| | `TF_IDF` | float | TF-IDF вес | Вычислено |
| **Фонетические** | `Word_Pronunciation_Complexity` | int (1–4) | Сложность произношения | Вычислено алгоритмически |
| | `syllable_count` | int | Количество слогов | Вычислено |
| | `vowel_count` | int | Количество гласных букв | Вычислено |
| | `consonant_count` | int | Количество согласных букв | Вычислено |
| **Сложность** | `Word_Complexity` | int | Интегральная сложность (комбинированный показатель) | Вычислено |
| | `Flesch_Reading_Ease` | float | Индекс удобочитаемости | Вычислено (для отдельных слов даёт выбросы) |
| **Энтропия / полярность** | `Word_Entropy` | float | Энтропия (непредсказуемость в контексте) | Информационная теория |
| | `Word_Polarity` / `polarity` | float | Полярность (0 – нейтральное, >0 – позитивное, <0 – негативное) | TextBlob / VADER |
| | `subjectivity` | float | Субъективность (0 – объективное, 1 – субъективное) | TextBlob |
| **Технические** | `is_stopword` | int (0/1) | Является ли слово стоп-словом | NLTK |
| | `word_length` | int | Длина слова (дублирует `len`) | Вычислено |
| | `word_numerical` | int | Числовой идентификатор слова | Присвоен автором |
| | `Word_Morphology_encoded` | int | Закодированная морфологическая структура | Вычислено |

## 3. Качество данных

| Параметр | Оценка |
|----------|--------|
| **Пропуски** | Отсутствуют |
| **Дубликаты** | Отсутствуют |
| **Согласованность** | Высокая. Значения соответствуют ожидаемым: у коротких частотных слов ниже сложность, у длинных редких — выше |
| **Выбросы** | Есть (например, отрицательные значения `Flesch_Reading_Ease` для отдельных слов) |
