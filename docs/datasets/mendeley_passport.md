# Паспорт датасета: Mendeley Word Difficulty Dataset (7 колонок)

**Файл:** `data/datasets/mendeley_7cols.xlsx`  
**Количество строк:** 5 368  
**Количество колонок:** 7

---

## 1. Общая информация

| Поле | Значение |
|------|---------|
| **Название** | Dataset for classifying English words into difficulty levels by undergraduate and postgraduate students |
| **Автор / публикатор** | Nisar Kangoo (Lovely Professional University, Faculty of Technology and Sciences) |

---

## 2. Структура данных

| Колонка | Тип | Описание | Примечание |
|---------|-----|----------|------------|
| `word` | string | Английское слово | Уникальный идентификатор |
| `fre` | integer/float | Частота слова в корпусе | Источник частоты не указан |
| `len` | integer | Длина слова в буквах | Вычисляется из `word` |
| `ps` | string | Часть речи | noun, verb, adjective и т.д. |
| `level` | integer | Уровень сложности (0 или 1) | В описании на Mendeley не упоминается |
| `difficult_ug` | integer / hyphen | Количество студентов бакалавриата, отметивших слово как сложное | `-` означает, что слово не было в тексте для этой группы |
| `difficult_pg` | integer / hyphen | Количество студентов магистратуры, отметивших слово как сложное | `-` означает, что слово не было в тексте для этой группы |

**Важно:**  
- 680 слов отмечены как сложные студентами бакалавриата  
- 151 слово — студентами магистратуры  
- 4 537 слов считаются «лёгкими» (не отмечены как сложные)

## 3. Качество данных

| Параметр | Оценка |
|----------|--------|
| **Пропуски** | Есть в виде прочерка (`-`) в `difficult_ug` и `difficult_pg` — слово не предлагалось соответствующей группе |
| **Дубликаты** | Отсутствуют |
| **Сбалансированность** | Не сбалансирован: лёгких слов (4 537) значительно больше, чем сложных |
| **Согласованность** | Высокая, данные собраны в едином протоколе |
